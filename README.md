# XingTu CLI · 零依赖开发者命令行工具

> 纯 Shell 实现，零依赖，即拉即用。

## 🎯 这是什么

`xingtu-cli` 是行途开源矩阵的 **CLI 工具资产仓**。收录零依赖、可独立执行的命令行工具，覆盖网络诊断、安全删除、备份、契约校验等日常开发场景。

## 📦 安装

```bash
# 拉取
git clone https://github.com/xingtu1996/xingtu-cli.git
cd xingtu-cli

# 加入 PATH
export PATH="$PWD/bin:$PATH"
```
